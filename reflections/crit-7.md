# Crit 7 reflection

**What was the breakthrough that moved the work forward?**

The breakthrough that moved the work forward was identifying the key areas of improvement that would have the greatest impact on the existing system. Initially, I focused on relatively low-hanging fruit, such as straightforward visual improvements. However, I realised that these incremental changes would not be sufficient to actually improve the overall user experience. Instead, I needed to step back and consider the experience as a whole and identify major improvement points, such as implementing a fine-grained search functionality. This shift in perspective made the proposed changes more coherent and ensured that they addressed actual user needs rather than simply improving individual aspects of the interface.

**What did this work change about who I want to be as a software developer?**

This crit highlighted the importance of establishing clear goals before starting implementation as a software developer. Rather than immediately focusing on individual features or visual improvements, I want to first understand the user experience as a whole (i.e., Double Diamond model). Only after establishing this direction does it become effective to use an agentic helper, to implement changes. Otherwise, it becomes easy to produce a collection of individually seemingly improved features without a coherent overall purpose. Going forward, I want to become a developer who always first defines the problem clearly.
